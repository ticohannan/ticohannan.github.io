Wolfram Demonstrations: Browser Ports

JavaScript · SVG · three.js / WebGL · Playwright

Forty Mathematica Manipulate demonstrations on robot motion planning, kinematics and geometry, rewritten as a static website that runs entirely in the browser. Highlights include visibility-graph path planning, probabilistic roadmaps, RRT and RRT*, Dubins and Reeds–Shepp car paths, Denavit–Hartenberg parameters, and manipulability ellipsoids.

40 interactive demos no build step checked against the Mathematica originals

Basketball Drop-Impact Simulator

Python · SciPy · Jupyter · v1.2.0

An interactive notebook that predicts the force a floor feels when a basketball lands, how long the ball stays in contact, and where the impact energy goes. The ball is modeled as an adiabatic gas spring plus a thin rubber shell with Hunt–Crossley damping, calibrated so a regulation ball passes the FIBA rebound test.

12 ft drop, 8 psi: ≈12.0 ms contact peak force ≈1300 N 23 tests passing
Screenshots and docs Source

ROT3U Robot-Arm Firmware

Arduino C++ · Python · GitHub Actions

Firmware and PC tools for calibrating and driving low-cost 6-servo desktop arms, written for a robotics course (ECE 6311) and built to be reused. A joint-mapping sketch measures each servo's range, pulse-to-angle curve and backlash; an inverse-kinematics sketch lists every solution for a target pose and picks and stacks blocks on a graph-paper grid.

Arduino Mega 2560 + PCA9685 PC simulation test suite on every push
